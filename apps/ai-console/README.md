# AI Backend Console

Flowcheck 제품 프론트와 분리된 AI 백엔드 전용 Next.js 콘솔이다.

## 기능

- 자연어 태스크 생성 요청
- 생성 태스크 편집·추가·삭제
- 사용자 사진과 선택형 모범 사진 업로드 검증
- PHOTO 태스크의 기대 판정·사진·실행 결과를 유지하는 벤치마크와 JSON 보고서
- 사장이 기록한 매장 정보에 근거한 알바생 질문 답변 테스트
- OpenRouter Luna ↔ Cerebras Gemma 4 31B 전환
- 태스크 생성·사진 검증 프롬프트 편집

벤치마크 사진은 파일당 10MB, 브라우저 전체 1GB까지 IndexedDB에 자동 저장됩니다. 전체 실행은 최대 4개 요청을 병렬 처리하며 실제 응답 모델, 일치율과 평균 시간을 표시합니다. 상세 보고서에는 실행 시 최초 AI 호출에 사용한 유효 프롬프트가 포함됩니다.

제공사 API 키는 브라우저에서 조회하거나 수정하지 않는다. `OPENROUTER_API_KEY`, `CEREBRAS_API_KEY`는 AI 백엔드의 환경변수 또는 OCI Secret으로 관리하며, 콘솔에는 설정 여부만 표시된다.

## 실행

AI 백엔드를 먼저 8000 포트로 실행한다. 콘솔은 기본적으로 `http://127.0.0.1:8000`에 연결하므로 공유 토큰만 필요하다.

```text
AI_SERVICE_TOKEN=<백엔드와 공유하는 토큰>
```

백엔드 주소가 다를 때만 콘솔 서버 환경의 `AI_BACKEND_URL`을 덮어쓴다.

그다음:

```bash
npm install
npm run dev
```

브라우저 요청은 항상 같은 출처의 `/api/ai` 프록시를 거친다. 백엔드 주소와
서비스 토큰은 콘솔 서버 환경에서만 읽으며 브라우저에 전달하거나 저장하지
않는다. 따라서 콘솔 사용자는 별도의 URL이나 Bearer 키를 입력하지 않는다.
